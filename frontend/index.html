操作：在 3D 视图拖动旋转、滚轮缩放；在三个切面上点击或拖动移动十字光标，滚轮逐层翻页。 "剖切"沿视线方向切开脑组织，切面显示为不透明的斜切片。

实现：同一套 C++17 代码编译成两个版本——桌面版（GLFW + OpenGL 3.3，Linux / Windows / macOS）和这里的网页版 （Emscripten → WebAssembly + WebGL2，即 OpenGL ES 3.0）。渲染全部在浏览器本地 GPU 上完成，与右上角选择的推理后端无关。
